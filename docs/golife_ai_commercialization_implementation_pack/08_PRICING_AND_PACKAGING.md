# Pricing and Packaging

## Positioning
Price as privacy-first personal productivity/decision support, not health/therapy/legal/finance.

## Package hypothesis
Free: acquisition.
Premium: core monetization.
Pro: later, only if deeper features are implemented.

## Example price bands
These are hypotheses, not final prices:

```text
Monthly: 4.99–7.99
Annual: 39.99–59.99
Trial: 7 days
```

## Margin controls
Track:
- AI cost per user;
- storage cost;
- support cost;
- payment fees;
- refund rate;
- gross margin.

## Rule
Do not sell what is not implemented.
