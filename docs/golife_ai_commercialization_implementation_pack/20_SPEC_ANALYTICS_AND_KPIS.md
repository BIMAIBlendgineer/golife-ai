# SPEC — Analytics and KPIs

## North Star
Weekly active users completing at least one mission and submitting feedback.

## Product KPIs
- mission set generated;
- mission completion;
- feedback rate;
- mission rejection;
- retention;
- fallback rate;
- privacy export/delete usage.

## Monetization KPIs
- trial start;
- trial conversion;
- paid conversion;
- churn;
- refund rate;
- ARPU;
- LTV;
- CAC;
- gross margin;
- AI cost per active user.

## Safety KPIs
- policy blocks;
- unsafe input rate;
- user reports;
- support escalations.
