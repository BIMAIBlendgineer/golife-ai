# Implementation Roadmap

## Phase 0 — Commercial scope freeze
Freeze claims and feature scope.

## Phase 1 — Device/store readiness
Android/iOS QA, screenshots, legal URLs.

## Phase 2 — Billing and entitlement
Provider, receipt validation, restore, refunds.

## Phase 3 — Production deployment
Production env, `/ready`, secrets, admin protection.

## Phase 4 — Analytics/KPI
Product events, monetization metrics, cost tracking.

## Phase 5 — Soft launch
Limited geography, EN/ES, monitor retention/cost/support.

## Phase 6 — Paid launch
Activate subscriptions and support runbooks.

## Phase 7 — Scale
Translations, stronger evals, platform runners, enterprise roadmap if needed.
