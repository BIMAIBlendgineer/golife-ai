# SPEC — Privacy and Data Safety

## Data map
Track:
- local LifeGraph;
- evidence refs;
- feedback metadata;
- AI prompts/outputs;
- export/delete jobs;
- admin telemetry;
- billing entitlements;
- support metadata.

## Store declaration rule
App privacy and data safety declarations must match behavior and third-party SDKs.

## Privacy principle
Do not claim no data collection if telemetry, billing, support, export/delete or AI provider processing is present.

## Required
- privacy policy;
- data map;
- deletion process;
- export process;
- third-party processor inventory.
