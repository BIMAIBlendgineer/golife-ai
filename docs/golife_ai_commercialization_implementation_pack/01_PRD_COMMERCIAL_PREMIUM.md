# PRD — Commercial Premium GoLife AI

## Product thesis
GoLife AI is a local-first daily decision system that converts real user evidence into three ranked daily missions with explanation, privacy filtering and feedback learning.

## User problem
Users suffer from decision fatigue, fragmented personal signals and too much generic AI output.

## Value proposition
GoLife AI gives the user a small actionable set of daily decisions, not a freeform chatbot.

## Core flow
```text
capture reality
→ structure evidence
→ privacy filter
→ AI mission planning
→ ranked mission set
→ feedback
→ safe learning
```

## Release positioning
Allowed:
- privacy-first daily missions;
- local-first evidence;
- explainable ranking;
- feedback learning;
- export/delete support.

Not allowed:
- therapy;
- medical/legal/financial advice;
- enterprise-ready claim;
- full global multilingual parity unless implemented.
