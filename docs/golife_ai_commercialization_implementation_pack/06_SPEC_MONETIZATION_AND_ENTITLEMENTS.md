# SPEC — Monetization and Entitlements

## Recommended initial model
Freemium + subscription.

## Free
- limited daily mission generation;
- limited refreshes;
- basic feedback;
- local-first use;
- privacy controls.

## Premium
- full mission set;
- higher refresh quota;
- feedback-backed learning;
- explanation/ranking trace;
- export bundle;
- backup/sync if implemented;
- stronger privacy controls.

## Pro / later
Only after implementation:
- deeper history;
- family/workspace;
- enterprise;
- OIDC/SSO.

## Entitlement rule
Every monetized capability must be server-gated.

## Monetization KPIs
- trial start rate;
- paid conversion;
- churn;
- refund rate;
- AI cost per active user;
- gross margin;
- mission completion;
- feedback rate.
