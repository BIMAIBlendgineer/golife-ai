# Release Gates

## Gate 1 — Scope integrity
No unsupported claims.

## Gate 2 — Technical validation
AI Gateway, backend, mobile, admin, gitleaks, CI.

## Gate 3 — Production environment
Mock disabled, live AI config, `/ready`, secrets externalized.

## Gate 4 — Device QA
Android/iOS, secure storage, export retrieval, offline/degraded UX.

## Gate 5 — Monetization
Billing provider, receipt validation, entitlements, restore purchases.

## Gate 6 — Store/legal
Privacy, terms, support URL, data safety, app privacy details, store assets.

## Gate 7 — Support/ops
Support, refund, privacy request, monitoring, incident process.
